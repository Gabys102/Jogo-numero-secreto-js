# 🎮 Jogo do Número Secreto

Um jogo simples e interativo desenvolvido com **HTML, CSS e JavaScript**, onde o jogador deve adivinhar um número secreto gerado aleatoriamente pelo sistema.

## 🚀 Acesse o Projeto

🔗 Demo: https://jogo-numero-secreto-ten-blue.vercel.app/


---

## 📖 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais de JavaScript, como:

* Manipulação do DOM
* Eventos de clique
* Estruturas condicionais
* Funções
* Geração de números aleatórios
* Validação de entrada do usuário

O jogo fornece dicas ao jogador informando se o número secreto é maior ou menor que o valor informado, tornando a experiência mais dinâmica e divertida.

---

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

---

## 🎯 Funcionalidades

✅ Geração aleatória do número secreto

✅ Validação dos palpites do jogador

✅ Dicas para auxiliar na descoberta do número

✅ Contador de tentativas

✅ Reinício da partida sem recarregar a página

✅ Interface simples e intuitiva
